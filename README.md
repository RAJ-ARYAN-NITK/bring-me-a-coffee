# ☕ Bring Me a Coffee — A Patreon-Inspired Support Platform

[![GitHub Stars](https://img.shields.io/github/stars/RAJ-ARYAN-NITK/bring-me-a-coffee?style=social)](https://github.com/RAJ-ARYAN-NITK/bring-me-a-coffee)
[![Forks](https://img.shields.io/github/forks/RAJ-ARYAN-NITK/bring-me-a-coffee?style=social)](https://github.com/RAJ-ARYAN-NITK/bring-me-a-coffee)

**Bring Me a Coffee** is a full-stack Patreon-style donation platform where fans can support creators financially by "buying them a coffee" using Razorpay integration. Creators can receive variable donations, and users can log in securely with authentication.

---

## 🚀 Features

- 🔐 **Secure Authentication** — via `NextAuth.js` with OAuth or email/password.
- 💳 **Payment Integration** — using **Razorpay** to allow flexible payments.
- 🖥️ **Creator Profiles** — where supporters can donate directly.
- 🧾 **Transaction Recording** — keeps track of who supported whom and how much.
- ✨ **Responsive UI** — styled with **Tailwind CSS** and built with **Next.js App Router**.
- 🧠 **Backend** — powered by `Express.js`, `Node.js`, `MongoDB`, and `Mongoose`.
